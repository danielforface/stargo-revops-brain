# Stargo RevOps Brain

A compact, auditable RevOps workbench for lead qualification, human sales decisions, weekly KPI reporting and AI visibility analysis.

> Engineering work in progress. This bootstrap establishes `main`; application code and verification evidence will be added after local validation.

## Principles

- Business qualification is deterministic; model output is untrusted and schema-validated.
- No automatic outbound messaging.
- Human decisions and provenance persist across restarts.
- Public source control does **not** contain employer-provided take-home input files.

See the original Stargo take-home pack for the authoritative business rules. The final setup and run commands will be documented as the implementation is committed.
